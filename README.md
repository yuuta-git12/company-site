# スカイライン・テクノロジーズ 企業サイト

ソフトウェアエンジニアリングスタジオ「スカイライン・テクノロジーズ」の企業サイトです。

## 概要

`index.html` 1ファイルで構成された、シングルページの静的サイトです。CSS と JavaScript はすべて同ファイル内に記述しており、ビルドや依存パッケージのインストールは不要です。

ページは以下のセクションで構成されています。

| セクション | 内容 |
| --- | --- |
| ヒーロー | キャッチコピーと、canvas で描画するスカイラインのビジュアル |
| フィロソフィー | 企業としての考え方 |
| サービス | カスタムソフトウェア開発 / クラウド・インフラ構築 / プロダクトデザイン（UI/UX） / DXコンサルティング |
| プロセス | プロジェクトの進め方 |
| 実績 | ROUTE+ / Nolt Pay / Mellow Health |
| 働く環境 | カルチャーや働き方の紹介 |
| お問い合わせ | 問い合わせ窓口 |

## ブラウザで開く手順

1. このリポジトリをクローンします。

   ```sh
   git clone <リポジトリのURL>
   cd company-site
   ```

2. `index.html` をブラウザで開きます。

   - **macOS**

     ```sh
     open index.html
     ```

   - **Windows**

     ```sh
     start index.html
     ```

   - **Linux**

     ```sh
     xdg-open index.html
     ```

   Finder やエクスプローラーで `index.html` をダブルクリックするか、ブラウザのウィンドウにドラッグ＆ドロップしても開けます。

### ローカルサーバーで確認する場合

`file://` ではなく `http://` で確認したい場合は、簡易サーバーを起動します。

```sh
python3 -m http.server 8000
```

起動後、ブラウザで <http://localhost:8000/> にアクセスしてください。
